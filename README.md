# 车载平衡滚球运动控制系统 — 2026 年 TI 杯 H 题

> 说明：仓库目录名 `medicine_car` 来源于赛前练习题目“智能送药小车”。实际参赛题目为 **H 题：车载平衡滚球运动控制系统**，本 README 及后续代码均围绕 H 题展开。

## 1. 项目概述

本项目设计了一辆能够在场地上移动并保持钢球平衡的小车。小车一边通过八路红外巡线模块沿赛道/标记点行驶，一边通过视觉识别获取水管内钢球的实时位置；主控板根据球的位置计算控制量，再驱动步进电机调整水管倾角，使钢球稳定在目标位置。

系统核心链路：

```textn钢球位置 ──▶ K230D 视觉识别 ──UART──▶ 主控 MSPM0G3507
                                         │
                                         ▼
                              运动规划 / 平衡控制算法
                                         │
                                         ▼
                              步进电机控制板 MSPM0G3507
                                         │
                                         ▼
                              步进电机 ──▶ 改变水管倾角 ──▶ 钢球位置
```

## 4. 各模块说明

### 4.1 视觉模块 `B_Vision/main.py`

- **硬件**：K230D（DNK230D）+ 摄像头
- **功能**：
  1. 开机菜单选择竖直零轴（`default` 用图像中心 / `new` 触摸标定），标定结果保存到 `/sdcard/axis_x.txt`。
  2. 每帧运行 YOLO11 检测钢球，取置信度最高目标。
  3. 计算钢球中心相对零轴的水平距离，按 `PX_TO_MM=0.5` 转换为毫米。
  4. 通过 UART 把 X 坐标发送给主控板。
- **模型**：`/data/marble_1.kmodel`
- **输出协议**：`[0xAA][0x01][DH][DL][CHECKSUM][0x55]`，`DH/DL` 为 `int16` 型 X 坐标（mm）。

详见 [`B_Vision/README.md`](B_Vision/README.md)。

### 4.2 主控板 `A_Driver/empty.c`

- **硬件**：MSPM0G3507
- **当前已实现**：
  - 八路红外巡线模块读取（`YB-MUXO4-2.0`），低电平有效。
  - 左右直流电机 PI 速度环 + 编码器测速。
  - UART 帧解析框架（可接收 K230D 数据，目前 `k230_handle_packet` 为占位）。
  - SSD1306 OLED 显示速度、巡线状态、错误码等。
- **待集成**：
  - 解析 K230D 发来的钢球 X 坐标。
  - 设计平衡控制算法（如 PID），根据 X 坐标生成目标水管倾角或步进脉冲。
  - 通过串口把控制量发送给步进电机控制板。

### 4.3 步进电机控制板（主板 2）

- **硬件**：MSPM0G3507 + 步进电机驱动器
- **机构**：水管一端用合页固定，另一端由步进电机（丝杆/摇臂等）调节高度，从而改变水管倾角。
- **功能**（待实现）：
  - 接收主控板下发的目标倾角或步进脉冲数。
  - 输出步进脉冲/方向信号，驱动电机到达目标位置。
  - 可加入限位开关、零点校准等保护逻辑。

### 4.4 ESP32-CAM 图传

- **用途**：通过 WiFi 把小车现场画面回传到电脑/手机，用于远程监控、录相和调试。
- **注意**：图传不参与实时控制闭环，控制闭环由 K230D + 主控板 + 步进板本地完成。

### 4.5 八路红外巡线

- **用途**：让小车在场地的 A/B/C/D 等标记点之间沿预定轨道移动。
- **模块**：`YB-MUXO4-2.0`，8 路输出。
- **当前策略**：读取 8 路传感器状态，加权计算偏差，通过 PI 速度环实现差速转向。

## 5. 通信协议

### 5.1 K230D → 主控板（钢球 X 坐标）

```textn帧格式：[0xAA][CMD][DH][DL][CHECKSUM][0x55]

CMD = 0x01：钢球相对零轴的 X 坐标（int16，单位 mm）
DH  = (x_mm >> 8) & 0xFF
DL  = x_mm & 0xFF
CHECKSUM = (CMD + DH + DL) & 0xFF
```

- 右侧为正，左侧为负。
- 当前 `B_Vision/main.py` 每 2 帧发送一次；未检测到钢球时发送上一帧有效坐标。

### 5.2 主控板 ↔ 步进电机控制板（待定义）

建议帧格式（与 K230 协议保持一致，便于复用解析代码）：

```textn[0xAA][CMD][DH][DL][CHECKSUM][0x55]

CMD 0x10 = 目标倾角（int16，单位 0.1° 或脉冲数）
CMD 0x11 = 步进使能/归零命令
CMD 0x20 = 步进板状态回传（0=正常，1=限位触发等）
```

> 具体协议待根据步进电机驱动方式和编码器反馈确定。

### 5.3 主控板 ↔ ESP32-CAM

- 仅用于视频流，一般采用 ESP32-CAM 默认的 `192.168.4.1` 或指定 IP 的 HTTP/MJPEG 流。

## 7. 开发流程

### 7.1 视觉调试

1. 将 `marble_1.kmodel` 放到 K230D `/data/`。
2. 用 CanMV IDE 运行 `B_Vision/main.py`，确认能检测到钢球并显示 X 坐标。
3. 点击触摸屏标定竖直零轴，或直接 `default` 进入运行。
4. 用串口助手查看 K230D 发送的 `0xAA ... 0x55` 数据帧。

### 7.2 主控板调试

1. 在 CCS 中导入 `A_Driver/empty.syscfg` 创建工程。
2. 编译烧录 `empty.c`。
3. 先用八路巡线确认小车能沿赛道直线/转弯行驶。
4. 接入 K230D UART，在 `k230_handle_packet` 中解析钢球 X 坐标，加入平衡控制算法。
5. 将控制量通过 UART 发送给步进控制板。

### 7.3 步进控制板调试

1. 新建 MSPM0G3507 工程，实现步进电机驱动（脉冲+方向）。
2. 接收主控板下发的目标倾角/脉冲数。
3. 连接水管机构，测试不同倾角下钢球的滚动响应。
4. 整定 PID，使钢球快速稳定在目标位置。

## 8. 注意事项

1. **共地**：K230D、MSPM0、电机驱动、巡线模块、步进驱动必须共地。
2. **电机供电**：直流电机和步进电机不要从 MSPM0 的 3.3V 取电，应接外部电源。
3. **UART 方向**：K230D GPIO40（TX）接 MSPM0 UART RX，GPIO41（RX）接 MSPM0 UART TX。
4. **模型路径**：`main.py` 中 `KMODEL_PATH = "/data/marble_1.kmodel"`，部署时务必确认文件存在。
5. **标定文件**：零轴保存在 `/sdcard/axis_x.txt`，更换场地/摄像头角度后建议重新标定。
6. **机械零点**：步进电机控制板建议加入限位开关或上电归零流程，防止累计误差。
